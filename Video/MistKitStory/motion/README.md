# Motion Graphics

Tool-agnostic specs live in [`specs/`](specs/), one file per graphic. Project files for whichever tool renders them (Remotion, Apple Motion, Keynote, …) go in `motion/project/`; renders are gitignored.

# M-<slug> — Title

- Chapter: NN
