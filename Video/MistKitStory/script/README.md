# Script

One file per chapter, named `<ID>-<slug>.md` to match [`../outline/outline.md`](../outline/outline.md).

Each file has frontmatter (`chapter`, `title`, `target_duration`, `sources`, `status`) and a two-column table:

| VO | Visual |
|----|--------|
| What is said | Shot ID (`03-04`), motion spec (`M-three-layers`), slide #, or screen capture |

Keep one beat per row so the shot list can be generated from the Visual column.
